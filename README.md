# en-met-fall-2026
This is Aastha Singh's Energy Meteorology project on data center heat islands. Written in Visual Studio Code using Python 3.14.8. 

This code pulls data from NASA satellites (Landsat 8, Landsat 9, and Sentinel-2) through Google Earth Engine, so a Google Earth Engine account is required to run this code (it will pop up automatically on your computer to authenticate). 

Before running, copy and paste this into your terminal: "pip install earthengine-api pandas numpy openpyxl".
